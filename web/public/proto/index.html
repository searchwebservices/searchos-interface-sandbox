How app pages plug in

  1. The sidebar gets an Apps section; each app page is a route under #/apps/<name>.
  2. Every app page has Jared docked on the right, so you can ask about what is on screen.
  3. Data comes from the console_* tables in the SearchOS DB through the console API.
  4. Same device gate as the lanes: no new login, no new door.
